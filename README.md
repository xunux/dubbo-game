# 🧱 MiniCraft — 迷你我的世界

一个纯浏览器运行的《我的世界》风格体素游戏，**单文件实现**（[minecraft.html](minecraft.html)），零安装、零构建，双击即玩。

基于 Three.js（CDN 加载，需联网），所有方块贴图均由 Canvas 程序化生成，无任何外部素材。

## ✨ 特性

- **三大维度**：🌍 主世界（256×256）/ 🔥 下界（岩浆海+要塞）/ 🌌 末地（浮空岛+黑曜石柱），按 `N` 穿越或点开始界面按钮
- **68 种方块**：泥土石砂、木材系、玻璃冰雪、矿石（煤/铁/金/钻石/青金石/绿宝石/石英）、地狱系、末地系、15 色羊毛等
- **方块变体**：台阶 / 楼梯 / 栅栏（橡木、圆石、石砖、砖块、下界砖），台阶楼梯可自动走上，栅栏自动连接相邻方块
- **生物系统**：猪、羊、牛、鸡（被动，被打逃跑）、老鼠、苦力怕（贴近自爆）、僵尸、僵尸猪人、末影人（受伤瞬移）、蝙蝠，有 AI、掉落物和种群重生
- **末影龙 Boss 战**：末地中央祭坛上空盘旋的巨龙（120 血 + Boss 血条 + 俯冲攻击），黑曜石柱顶的末地水晶会持续给它回血——先炸水晶再屠龙，掉落钻石/绿宝石
- **远古城市 + 坚守者**：主世界地下 3 座黑石大厅（紫珀祭坛、战利品矿石、地表黑石遗迹环入口），由 30 血 6 攻、近乎免疫击退的坚守者看守，靠近会听到逐渐加速的灵魂心跳
- **生存玩法**：生命值/摔落伤害、挖掘裂纹进度（按硬度计时）、掉落物磁吸拾取、合成台（13 条配方）、食物进食回血
- **TNT 爆炸**：引信倒计时 + 连锁引爆 + 冲击波伤害与镜头震动
- **建筑生成**：村庄小屋、瞭望塔、水井、下界要塞
- **程序化音乐**：Web Audio 实时合成，每个维度一首主题曲（主世界钢琴 / 下界低鸣 / 末地钟声），随机生成永不重复，`M` 开关
- **材质音效**：敲击 / 破坏 / 放置 / 脚步按方块材质区分（石、木、沙土、玻璃、矿石、树叶），另有挥空、命中、进食、受击等音效
- **音符盒**：木板+石英合成，右键逐级升调演奏（两个八度 25 个半音），配彩色音符粒子
- **其他**：第一/第三人称（F5）、飞行模式（双击空格）、掉落物丢弃（Q）、像素风程序化贴图

## 🎮 操作

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| WASD | 移动 | 左键(长按) | 挖掘 / 攻击 |
| 右键 | 放置 / 进食 | 中键 | 吸取方块 |
| 空格 | 跳跃 / 游泳 | 双击空格 | 飞行开关 |
| Shift | 疾跑 / 下降 | E | 物品库 / 合成 |
| N | 切换维度 | F5 / F3 | 切换视角 / 调试 |
| Q | 丢弃手持 | 滚轮 | 切换快捷栏 |
| H | 按键帮助面板 | M | 音乐 开 / 关 |

## 🚀 运行

直接用浏览器打开 `minecraft.html` 即可；或本地起个服务：

```bash
python -m http.server 8123
# 访问 http://127.0.0.1:8123/minecraft.html
```

> 提示：Three.js 从 CDN 加载，首次打开需联网；每次刷新生成随机世界。
